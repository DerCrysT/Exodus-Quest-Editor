Was ist das hier?

      
Dieses Tool baut die vier JSON-Dateitypen von ExodusQuests per Formular zusammen: Quests, NPCs,
         Dialoge und Stashes. Es läuft komplett im Browser — nichts wird hochgeladen, alles bleibt lokal. Entwürfe
         werden automatisch im Browser zwischengespeichert (localStorage) und bleiben beim nächsten Besuch erhalten.

      
Arbeitsablauf

      
    
        
  1. Tab wählen (Quest/NPC/Dialog/Stash) und das Formular ausfüllen. Die Vorschau rechts zeigt live das fertige JSON.
    2. 
        
  2. Mit Prüfen gegen die wichtigsten Regeln des Mod-Validators checken (fehlende Pflichtfelder,
            doppelte IDs, unbekannte Rangnamen, Komma-Listen, Ruf-Bereiche …). Das ersetzt nicht den echten
            Validator im Server-Log, hilft aber, die häufigsten Fehler vorher zu finden.
    3. 
        
  3. Mit JSON kopieren oder Herunterladen die Datei übernehmen und in den passenden
            Ordner im Server-Profil legen (Quest/, NPC/, Dialog/, Stash/,
            beliebig tief verschachtelt).
    4. 
        
  4. Bestehende Datei ändern? JSON laden… oder JSON einfügen… benutzen —
            das Formular füllt sich automatisch.
    5. 
      

      
Hinweise

      
    
        
  • Komma-getrennte Klassenlisten (z. B. TargetClass, ItemClass) zählen laut Mod
            gemeinsam zur selben Anzahl — das ist keine ODER-Quest, sondern eine Sammelmenge.
    • 
        
  • Rangnamen bei Ruf-Bereichen: Brother in Arms, Ally, Friend, Associate, Acquaintance, Neutral, Suspicious,
            Disliked, Enemy, Wanted, Execution Target. Groß-/Kleinschreibung und Leerzeichen sind egal.
    • 
        
  • Min/Max eines Ruf-Bereichs mit dem Wert 0 gelten dem Spiel als „nicht gesetzt“ (voller
            Bereich) — für „bis 0“ bitte MaxRank „Neutral“ verwenden. Das Tool warnt, falls das passiert.
    • 
        
  • Dieses Tool kennt die aktuellen Felder von ExodusQuests (Stand: Reputation-System, Zeitlimit, Start-Item-Rückgabe).
            Bei neuen Mod-Versionen kann es hinter den echten Schemas zurückbleiben — im Zweifel zählt
            docs/schemas/*.json im Mod-Repo.
    •
